Sobre o iDoc

Editor e visualizador de documentação técnica. Compartilhe por arquivos JSON exportados.

Armazenamento

Dados no localStorage do navegador. Limpar dados do site remove tudo — exporte regularmente.

Importação

Importar adiciona documentos — nunca sobrescreve. Cada importado recebe selo e pode ser excluído individualmente.

Menu de contexto

Clique com o botão direito em um documento (sidebar) ou em um bloco (editor) para ações rápidas.

Atalhos

Novo documentoCtrl N BuscarCtrl K Salvar (editando)Ctrl S Cancelar / fecharEsc

Segurança

Importe apenas arquivos confiáveis. HTML é sanitizado na importação.
